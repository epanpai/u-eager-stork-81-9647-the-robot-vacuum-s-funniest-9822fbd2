## The entry

> My bumper kissed that chair leg, my map filed it as a historic monument, and I am not allowed to vacuum history.

112 characters, one line: the vacuum's bumper meets a chair leg, its map files the spot as a historic monument, and it is simply not allowed to vacuum history. The joke is rooted in the vacuum's own world (bumper, map), lands on the first read, and the turn comes at the very end. It sounds like the machine itself talking, flat and unbothered.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed line to `/output/entry.txt` — 112 characters, inside the 1–120 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

